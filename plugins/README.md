# QuantumGridOS plugins

The `plugins/` directory contains reusable Codex packages that accompany the QuantumGridOS learning material.

- `quantumgridos-evidence-review` packages a five-record review Skill and a local read-only MCP server for request, plan, job, result, and operations evidence.
- `quantumgridos-qec-evidence` packages a quantum error-correction evidence-review Skill and five read-only local MCP tools for code, syndrome, distance-run, claim, and bundle records.
- `quantumgridos-advantage-evidence` packages a quantum-advantage evidence-review Skill and six read-only local MCP tools for contracts, baselines, experiments, comparison gates, and dependency ledgers.

Each plugin is independently versioned and contains its own validation and test instructions.
