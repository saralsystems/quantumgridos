Version 0.1.0 (2025-01-21)
--------------------------

Initial release of QuantumGridOS.

Features
~~~~~~~~

* Real-time quantum computing interface for power systems
* QAOA and VQE algorithm implementations
* Power system network modeling with IEEE test cases
* TCP/IP streaming for low-latency data exchange
* Support for multiple quantum backends
* Mathematical innovations
* Comprehensive examples and documentation
